# 文獻與證據
## 檢索
把問題拆成概念與同義詞，選領域適合的資料庫。教育社科不能只依醫學或預印本來源推定涵蓋。記錄實際來源、日期、檢索式、取得／篩選範圍與限制；沒有搜尋就交計畫。

引用鏈、網頁排名是發現線索，不證明完整性或研究品質。依指定範圍工作，不自行把一般回顧宣布為系統性回顧。

## 閱讀
- 核對識別碼與出版者等原始紀錄；預印本、正式版記明版本。
- access 使用 metadata / abstract / partial / full / unavailable，代表本次實際閱讀範圍。
- 摘要只能支持摘要層級描述。方法、限制、效果與機制須讀相應章節。
- 關鍵發現附頁碼、章節、表圖或段落定位，不猜頁碼。
- 書目身分、主張支持、版本／撤稿更正分開核對。無法取得全文保留待核狀態。

## 統整
用 [文獻模板](../assets/02-literature.md)，按問題、方法、測量、情境或理論比較一致與分歧，不以逐篇摘要代替綜合。不因作者未提就斷言領域沒有研究。交有來源的主題統整、缺口及補查項；重要資料同步到 research.json。
