# 審查與修訂
先檢查問題—方法、結果—主張、來源—引用及內部數值術語，再修語言。問題需附位置、依據、影響與動作；不虛構評分或專家身分。同一上下文多角度檢查應稱自查，不能聲稱互盲獨立評審。

## 引用
書目身分、主張支持、版本／撤稿更正分開處理。必要時回原始來源。DOI 正確不等於貼切，查不到不等於虛構，未讀全文需縮小判斷範圍。

## 處置
用 [修訂模板](../assets/05-revision.md)，作者可 accept / partial / decline / pending，記錄理由與位置。評論不改原稿；已授權範圍內例行錯字與一致性可直接修。核心解釋或研究問題變動由作者決定；不能為完成表格虛構同意。

修訂後核對各問題、新矛盾、數值／引用／術語與範圍外變動。回覆信只寫實際完成的修改，不能將計畫補分析寫成已做。

交所需報告、修訂稿、回覆與剩餘事項。「已處置」不等於「問題已解決」；拒絕建議有理由仍可能留下限制。
