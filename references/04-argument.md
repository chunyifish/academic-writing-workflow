# 結果與論證
輸入研究問題、設計、實際分析輸出及來源。分開觀察、計算、作者解釋與 AI 推測；核對樣本與分析單位，引文不是本研究結果。

1. 每項結果連到資料、程式輸出、表圖或質性材料位置。
2. 用 [論證模板](../assets/04-argument.md) 記主要主張及 supporting / contradicting / mixed / not_checked，允許不支持原假設。
3. 校準描述、關聯、因果強度。機制與遷移性需額外依據，不從顯著性直接推重要性。
4. 不顯著不等於無效果，呈現可用效果量、不確定性與限制；無輸出不造 p 值或區間。
5. 質性主張附材料與脈絡，保留反例，不用引句數量代替詮釋。
6. 先寫核心論證再排章節與圖表；不能把改變結論的證據藏入補充材料。

交證據表、核心論證、大綱、圖表及未支持主張。資料不足只給暫定大綱與缺口；主要主張改變時列出需同步更新的摘要、討論與結論。
