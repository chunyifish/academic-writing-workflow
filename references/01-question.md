# 問題形成
接受興趣、觀察、初步問題或已有簡報。先辨認作者要提問引導或候選提案；沿用明確指示，不默認人人都需要長輪次對話。

1. 分開研究現象、改善目標與可回答問題。「提升反思」是目標，尚需界定如何觀察反思。
2. 辨認對象、情境、概念、分析單位、可取得資料，以及描述、比較、關聯、機制探索或因果估計的目的。
3. 指出替代解釋與可行性限制；新穎性待文獻核對，不聲稱沒有人研究。
4. 需要時聚焦一至三個影響最大的問題。使用者要求提案可直接提出候選，標為 AI 建議，不記成作者已決定。
5. 用可觀察語言寫問題，保留探索性研究的開放性，不強制質性問題變成變項關係。

使用 [簡報模板](../assets/01-question-brief.md)，交問題、理由、對象／情境、證據需求、界線、作者決定與未決事項。後續文獻可要求重新界定。
